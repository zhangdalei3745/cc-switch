2. 合并策略

决策点处理规则理由
上游架构mode/controller/live projection、managed accounts、route/aggregation mode、full-url、Copilot、xAI/Grok 保持 upstream 实现。避免 JoyCode 分支回填旧 takeover 大文件逻辑，保证后续 rebase 成本最低。
JoyCode UI恢复 providerType="joycode"、JoycodeConnectionFields、登录凭证、内外网与租户字段到新的 ProviderForm 架构。JoyCode 是独立 provider type，不是普通 API Key provider。
协议转换保留 JoyCode Responses / Anthropic / Chat Completions 的 per-model wire API 与模型元数据；同时保留上游 xAI/Copilot Responses 修复。三类能力互不替代，避免任何一个 provider 的兼容逻辑造成其他 provider 回归。
xAI vs JoyCodexAI/Copilot Grok 的 integer normalize 为独立 gate；JoyCode 只进入 namespace flatten/restore。JoyCode 不需要 xAI 的 whole-float 参数重写，混用会引入新的请求语义问题。
测试以 JoyCode targeted tests + Rust 全量测试 + typecheck 作为禁用回归门槛。大版本合并不能只依赖人工浏览 diff。

4. Claude Anthropic JSON → SSE fallback 流程

client 请求 stream=true
        |
        v
upstream 返回 application/json 并拒绝/不处理请求
        |
        v
is_unprocessed_max_output_rejection(body, status)
        |  判定发生在 responses_to_anthropic... 消费 body 之前
        v
responses_to_anthropic_with_web_search_options(body)
        |
        v
message.content 是否为空数组？
        |-- 是 + confirmed rejection:
        |       message_start
        |       event: error  → Upstream rejected the request before processing
        |       （不输出 max_tokens / message_stop）
        |
        |-- 否:
        |       正常 Anthropic SSE 生命周期
修复后的关键点：Rubric 不是“发现 incomplete 就报错”，而是“零 usage + no/empty output + max_output_tokens”才视为上游未处理；有真实 token 或内容时仍然保持 max_tokens 截断语义。

5. xAI rewrite 与 JoyCode namespace restore 分离

provider_needs_xai_native_responses_rewritexAI OAuth / xAI API key / api.x.ai / Copilot Grok 场景；负责 whole-float integer normalize。
→
Normalized Responses rewrite只改变 xAI/Copilot Grok 需要的请求参数；不作用到 JoyCode。
provider_needs_responses_namespace_flattenJoyCode native Responses / xAI namespace 场景 / Copilot Grok based on outbound_model。
→
Namespace restore按 restore_map 恢复命名空间；integer normalize 由布尔参数显式传入。
forwarder:
if provider_needs_responses_namespace_flatten(provider, outbound_model) {
    let normalize_integer_arguments =
        provider_needs_xai_native_responses_rewrite(&provider);

    handle_codex_native_responses_namespace_restore(
        response, ctx, state, guard, restore_map,
        normalize_integer_arguments
    )
}

JoyCode      -> flatten = true,  normalize_integer_arguments = false
xAI OAuth    -> flatten = true,  normalize_integer_arguments = true
Copilot Grok -> flatten 视 outbound_model, normalize 视 provider gate
其他 provider -> 均为 false
